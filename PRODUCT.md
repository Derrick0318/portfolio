# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters, lecturers, peers, and internship reviewers who need to quickly understand Derrick's Computer Science academic projects and open working previews.

## Product Purpose

The portfolio collects four academic projects in one website: Crop Yield AI, 168 Park Selayang, M4Food, and UTSmartBot. Success means visitors can understand the project purpose, Derrick's role, the stack, and then enter each project page or demo.

## Positioning

The portfolio is a project showcase that keeps every project's original interface separate while making the main page feel professional, high-end, and easy to review.

## Operating Context

Visitors browse on desktop and phone. The site is deployed from GitHub to Vercel, with local Flask preview during development.

## Capabilities and Constraints

Project order: Crop Yield AI, 168 Park Selayang, M4Food, UTSmartBot. Project role and stack must remain visible. Contact details appear in the footer. The main page should not reuse project photos as a generic hero background.

## Evidence on Hand

Existing Flask templates, portfolio CSS, project demo pages, supplied project assets, and pushed GitHub repository `Derrick0318/portfolio`.

## Product Principles

Keep the first page clean and memorable.
Keep project demos separated from the portfolio presentation.
Prioritize mobile responsiveness.
Avoid exaggerated effects that make the portfolio look childish.
